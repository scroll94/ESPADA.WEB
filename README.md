# ESPADA — студия сайтов

Сайт-визитка: https://scroll94.github.io/ESPADA.WEB/

- `index.html` — главная (тарифы, сравнение, вопросы, контакты)
- `simple.html` — макет тарифа «Простой» (LILA)
- `designer.html` — макет тарифа «Дизайнерский» (PULSE)

Цены, WhatsApp, Telegram и 2ГИС меняются в блоке `CONFIG` в начале скрипта `index.html`.
